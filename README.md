# A3S Digital Technologies

> **Build. Brand. Market. Grow.**  
> Official marketing website for A3S Digital Technologies, a premier digital solutions agency based in Madurai, Tamil Nadu, India.

---

## 🚀 Features

- **Multi-Page Experience**: Home, Services, 5-Step Process, Portfolio Showcase with interactive category filters and project modals, About Us with 4 foundational pillars and 6-item advantage checklist, Engineering Blog, Contact page with validation and embedded Google Maps, and FAQ accordion.
- **Brand System**: Custom color tokens (Teal `#17A1AB`, Mint `#4DC3B7`, Purple `#403458`, Blue `#0065AB`, Deep Navy `#0A0E1A`).
- **Modern Tech Stack**: React 18, Vite, Tailwind CSS, Lucide React, Framer Motion.
- **Responsive & Accessible**: Mobile-first design, WCAG AA contrast compliance, sub-second Core Web Vitals performance.

---

## 🛠️ Tech Stack

- **Framework**: React 18
- **Bundler**: Vite
- **Styling**: Tailwind CSS
- **Routing**: React Router DOM v6
- **Icons**: Lucide React
- **Animations**: Framer Motion

---

## 📦 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```
